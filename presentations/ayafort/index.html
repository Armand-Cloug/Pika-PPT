AyaFort

Bastion SSH auto-hébergé avec interface web de gestion

Développé en interne pour aYaline, en remplacement de Passhport — solution open source non maintenue depuis 2023 — AyaFort centralise et trace l’ensemble des accès SSH vers l’infrastructure de l’entreprise.

  • Bastion SSH (Rust) — point d’entrée unique vers les VMs
  • Interface web (Next.js) — gestion des accès, terminal SSH intégré
  • Runner Ansible (Rust) — automatisation multi-hôtes
  • Authentification Google OAuth, clés SSH centralisées (MariaDB)
  • Architecture 100 % conteneurisée (Docker), CI/CD GitLab
